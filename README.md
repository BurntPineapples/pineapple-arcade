# 🍍 Pineapple Arcade

895 browser games in one place. Forgiving search (typos, no spaces, initials like "fnf"), categories, favorites, continue-playing, and play time. Game saves persist per device; use Backup/Restore to move favorites and history.

Play: https://burntpineapples.github.io/pineapple-arcade/

Test the search: `node test-search.js`
